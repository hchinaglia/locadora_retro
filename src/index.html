⚡ TRANSFERÊNCIA & INSTALAÇÃO
📥 BAIXAR APK DIRETO (266 MB)
📱 Escanear no Celular (Mesmo Wi-Fi)

Aponte a câmera do seu smartphone para o QR Code ao lado para baixar instantaneamente pela rede local:

  1. Baixe o arquivo Munchkin-v2.1.0-PTBR.apk tocando no botão acima ou escaneando o QR Code.
  2. Abra o arquivo baixado. Se o Android exibir o aviso "Para sua segurança, seu telefone não tem permissão para instalar apps desconhecidos desta fonte", toque em Configurações e ative Permitir desta fonte.
  3. Toque em Instalar e depois em Abrir para jogar em Português!

Melhor experiência (60 FPS nativo sem travamento e com áudio): O jogo roda no celular e a tela é espelhada no Linux com controle via mouse e teclado.

  1. Instale o ADB e o Scrcpy no Linux:
    sudo apt install scrcpy adb
  2. No celular, ative a Depuração USB (em Configurações > Opções do desenvolvedor) e plugue o cabo USB no PC.
  3. Instale o APK no celular direto pelo terminal do Linux:
    adb install public/apks/Munchkin-v2.1.0-PTBR.apk
  4. Inicie o jogo em tela cheia no Linux:
    scrcpy --stay-awake --shortcut-mod=lctrl

Android nativo dentro do Linux (sem celular): Roda o Android compartilhando o kernel com aceleração gráfica pela GPU.

  1. Instale o Waydroid no Linux:
    sudo apt install waydroid
  2. Como o APK é arm64-v8a, instale a camada de tradução ARM (libndk):
    sudo apt install python3-pip lxc curl -y git clone https://github.com/casualsnek/waydroid_script cd waydroid_script && python3 -m venv venv && ./venv/bin/pip install -r requirements.txt sudo ./venv/bin/python3 main.py install libndk
  3. Instale e execute o Munchkin:
    waydroid app install public/apks/Munchkin-v2.1.0-PTBR.apk waydroid app launch com.direwolfdigital.munchkin
